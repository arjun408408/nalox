Nalox — Offline Brain Setup / Ollama (একবারই লাগবে / one time only)
====================================================================
এটা OPTIONAL — না করলেও Nalox চলবে। কিন্তু এটা করে রাখলে
ইন্টারনেট না থাকলেও, সব cloud AI (FreeLLMAPI / Gemini / Groq)
একসঙ্গে down হলেও Nalox তোমার কথার উত্তর দিতে পারবে — কারণ
তখন brain টা চলবে তোমার নিজের laptop-এর ভেতরেই, সম্পূর্ণ FREE,
কোনো key লাগে না। মোট ৫-১০ মিনিট লাগবে (model download-এর
সময়টা ইন্টারনেটের speed-এর ওপর নির্ভর করে)।

Follow these 3 steps once, on your laptop:

1) Ollama install করো
   - Browser-এ যাও: ollama.com
   - "Download" → Windows version টা download করে install করো
     (সাধারণ next-next install, কোনো account লাগে না)।
   - Install হলে Ollama নিজে থেকেই background-এ চলতে থাকে —
     system tray-তে ওর icon দেখতে পাবে।

2) Model দুটো নামাও (brain + চোখ)
   - Start menu-তে "PowerShell" বা "Terminal" খোলো।
   - একে একে ঠিক এই দুটো লাইন লিখে Enter চাপো:

         ollama pull qwen3:8b
         ollama pull qwen3-vl:8b

   - প্রথমটা (~5 GB) হলো brain — তোমার কথার উত্তর দেবে।
     দ্বিতীয়টা (~6 GB) হলো চোখ — Nalox তোমার screen
     দেখে বলতে পারবে স্ক্রিনে কী আছে (শুধু লেখা পড়া না,
     পুরো ছবিটাই দেখে বুঝবে)।
   - Download শেষ হলে "success" লিখবে। এই একবারই
     ইন্টারনেট লাগবে; এরপর থেকে model গুলো তোমার
     laptop-এই থাকবে, ইন্টারনেট ছাড়াই চলবে।
   - তোমার PC-তে NVIDIA graphics card (8 GB VRAM)
     আছে — Ollama model গুলো নিজে থেকেই ওই GPU-তে
     চালাবে, তাই উত্তর আসবে অনেক fast।

3) GPU-তে চলছে কিনা যাচাই করো (একটা command)
   - Nalox চালু রেখে ওকে বলো: "আমার স্ক্রিনে কী আছে?"
   - তারপর PowerShell-এ এই লাইনটা চালাও:

         ollama ps

   - Model-এর নামের পাশে "100% GPU" লেখা থাকলেই বুঝবে
     সব ঠিক আছে — model টা graphics card-এই চলছে।

4) Nalox restart করো
   - Nalox-এর tray icon → Restart (অথবা Nalox বন্ধ করে আবার
     চালু করো)।
   - Log-এ (📋 Log) এই লাইনটা এলেই বুঝবে হয়ে গেছে:
         [BRAIN] Offline brain (Ollama) ready: qwen3:8b

ব্যস! এরপর থেকে সব cloud brain down হলেও Nalox চুপ করে
থাকবে না — laptop-এর ভেতরের brain দিয়ে উত্তর দেবে,
বাংলাতেই (তোমার শেখানো ভাষাতেই)।

জরুরি কথা / Notes:
- Model দুটো laptop-এ জায়গা নেবে (সব মিলিয়ে ~11 GB)
  আর cloud-এর চেয়ে উত্তর দিতে একটু বেশি সময় নিতে
  পারে — তবে তোমার GPU থাকায় screen পড়াটা fast-ই হবে।
  Brain টা শেষ ভরসা (last resort), প্রতিদিনের brain না;
  চোখের model টা শুধু screen দেখার সময়ই জাগে।
- অন্য model চাইলে Settings-এ না গিয়ে PowerShell-এ
  `ollama pull qwen2.5:7b` বা `ollama pull llama3.1:8b`
  চালালেই Nalox নিজে খুঁজে নেবে — কোনটা আছে সেটা ও নিজেই
  চেষ্টা করে দেখে (model walk)।
- Ollama uninstall করলে বা বন্ধ রাখলেও কোনো ক্ষতি নেই —
  Nalox আগের মতোই cloud brain দিয়ে চলবে।

(English summary: Install Ollama from ollama.com, run
`ollama pull qwen3:8b` (the brain) and
`ollama pull qwen3-vl:8b` (the eyes — Nalox reads your
screen with it) once in PowerShell, restart Nalox. Ask
Nalox "what is on my screen?" and run `ollama ps` — the
model should show "100% GPU" on your NVIDIA card. Free,
no account, no key. Afterwards Nalox keeps answering —
in Bengali — even with no internet and every cloud AI
down, and it can describe your screen fully offline.)
