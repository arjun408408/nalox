NALOX UPDATE v6.3 — কানের timeout-loop fix + fast AI switch + বাংলা
====================================================================

১) 🎧 কানের timeout-loop এবার মরে গেল (v6.2-র আসল বাগ):
v6.2-তে দেখা গেছিল — "[ears] worker restarted (timeout)"
কয়েক সেকেন্ড পরপর আসতেই থাকে, শেষে "restarting too often
— pausing" হয়ে কান বন্ধ হয়ে যেত। কারণ: নতুন worker
model load শেষ করার আগেই পুরনো deadline তাকে মেরে ফেলত,
আবার নতুনটা আসত, আবার মরত — এই loop থামতই না। এবার:
 • Worker আগে "ready" বলবে (model load শেষ), তারপর থেকে
   deadline গোনা শুরু — load-এর সময় কখনো deadline খায় না।
 • Wake শোনার সময় 4 সেকেন্ড থেকে বাড়িয়ে 8 সেকেন্ড।
 • Deadline পেরোলেই worker মারা নয় — আগে ping করে দেখা
   হয়: উত্তর দিলে ও শুধু slow, মরা না — ওকেই রাখা হয়।
 • পরপর timeout এলে কিছুক্ষণ নিজে নিজে pause নিয়ে আবার
   নিজেই সেরে ওঠে — কান কখনো permanently বন্ধ থাকে না।
 • একই log line বারবার আসা বন্ধ — log আর flood হবে না।

২) ⚡ AI switch এখন fast — কেউ দেরি করলেই পরেরজন:
আগে একটা AI আটকে থাকলে 25–45 সেকেন্ড পর্যন্ত অপেক্ষা
হতো। এবার প্রতিটা AI-র সীমা মাত্র 10 সেকেন্ড: FreeLLMAPI
10 সেকেন্ডে উত্তর না দিলে সঙ্গে সঙ্গে Claude, তারপর
OpenRouter, Gemini, Groq — পটপট switch হয়ে যাবে। Cloud
কানও (Gemini/Groq শোনা) 8 থেকে 6 সেকেন্ডে নেমেছে।

৩) 🗣️ কথা বলার default ভাষা এখন বাংলা:
তোমার শেখানো preference অনুযায়ী Nalox এবার default
বাংলায় কথা বলবে — তুমি English বললে English, Hindi
বললে Hindi উত্তর দেবে, কিন্তু ছোট/অস্পষ্ট কথায় default
বাংলা। Settings/logs-এর লেখা English-ই থাকছে, শুধু
কথা বলার ভাষাটা বাংলা-first হলো।

৪) 💬 Command Center-এর CHAT panel এবার শুধুই চ্যাট:
আগে chat-এর ভেতর [timing], [sys], [ears], [ERROR]-এর
মতো system লাইন ঢুকে যেত। এবার CHAT panel-এ শুধু
তোমার কথা (YOU) আর Nalox-এর উত্তর (NALOX) দেখাবে।
বাকি সব লাইন আগের মতোই 📋 Log page-এ থাকবে।

১) 🎧 কান (hearing) এবার আর কখনো আটকাবে না (hang fix):
আগে মাঝে মাঝে transcription আটকে যেত — "transcription stuck"
দেখা যেত, তারপরের command আর পৌঁছাতই না, "Wake up" বললেও
Command Center খুলত না। এবার সব শোনার কাজ (speech-to-text)
আলাদা একটা worker process-এ চলে গেছে: প্রতিটা শোনার
সীমা বাঁধা — wake word 4 সেকেন্ড, command 12 সেকেন্ড।
কোনোটা আটকে গেলে Nalox ওই worker-টাকে মেরে নতুন worker
চালু করে নিজে নিজেই সেরে ওঠে (log-এ দেখবে:
"[ears] worker restarted (timeout)")। তুমি শুধু বলতেই
থাকবে — মাঝখানে থেমে যাওয়া এবার শেষ।

২) 🖥️ "Wake up Nalox" = শুধুই Command Center:
এবার নিয়ম একটাই — "Wake up Nalox" বললে শুধু Command
Center-ই খুলবে, plain window টা আসবেই না। শুধু wake up
না: laptop চালু হলে (autostart), হাতে চালু করলে, update-
এর পর restart নিলে — প্রতিটা start-এই Nalox সোজা
Command Center খুলে হাজির হবে। Command Center খুললে
plain window থাকলে সেটা নিজে নিজে সরে যাবে।

৩) 🎬 Command Center-এর opening ceremony + বড় Level:
খোলার সময় ~1 সেকেন্ডের robotic ceremony: window fade
হয়ে আসবে, orb spin-up হবে ring sweep দিয়ে, বাম panel
তারপর ডান panel জ্বলবে, শেষে status pill-এ "● ONLINE"
আসবে। উপরে ⚡ Level এবার বড় করে দেখা যাবে — number,
word (Slow/Fast/Lightning) আর next level-এর progress
bar সহ। SYSTEM panel-এ নতুন: 📱 Phone (কোন phone
connected), 🎙 এই session-এ কটা command শুনেছে,
⏱ Uptime। আর Command Center-এর উপরেই এবার ⚙ Settings
আর 📋 Log button আছে — plain window খোলার দরকারই নেই।

৪) ⬛ Start-এ আর কালো window (console) আসবে না:
Nalox এখন পুরোপুরি silent start নেয় — কোনো কালো
console window উঠবে না, plain window-ও start-এ উঠবে না;
সোজা Command Center।

৫) 🔄 এবার থেকে Nalox নিজে নিজে update হবে:
Settings → Updates-এ repo আর token বসালেই এরপর থেকে
নিজে নিজে update হবে — UPDATE.bat আর চালাতে হবে না,
কখনোই না। নিয়মটা এমন:
  • Settings খোলো → নিচে "🔄 Updates" section।
  • "GitHub repo"-তে তোমার private repo-র নাম বসাও
    (যেমন: tomar-name/nalox)।
  • "GitHub token"-এ একটা read-only token বসাও
    (GitHub → Settings → Developer settings →
    Fine-grained tokens → শুধু ওই repo, Contents:
    Read-only)। ⚠️ Token টা শুধু laptop-এর Settings-এই
    বসাবে — chat-এ বা কাউকে কখনো পাঠাবে না।
  • Save করো। ব্যস — এরপর Nalox start হওয়ার ~1 মিনিট
    পর, আর তারপর প্রতি 6 ঘণ্টায়, নিজে check করবে;
    নতুন version থাকলে নিজে download করে লাগিয়ে
    restart নেবে, আর ফিরে এসে নিজেই বলবে:
    "I have updated myself to version X.Y, sir."
  • তোমার config, API key, custom command — কিচ্ছু
    বদলাবে না; update শুধু code বদলায়।
  • তখনই check করতে চাইলে ওই section-এই
    "🔍 Check for updates now" button আছে।

    "call my mother" / "মাকে কল করো" → ফোন থেকে কল যাবে,
    "ফোনে YouTube খোলো" → ফোনে YouTube খুলবে,
    ফোনের battery-ও মুখে জিজ্ঞেস করলেই বলে দেবে।
  • একবারের নোট: প্রথম install-এ Android একটা
    "unknown app" Allow চাইতে পারে — Allow করে দিও,
    এটা তোমার নিজের বানানো app, Play Store-এর বাইরে
    বলে Android ওই একবার সতর্ক করে।
  • app টা খুললে battery-optimization থেকে ছাড় দেওয়ার
    একটা পেজ আসতে পারে — এক ট্যাপে Allow করে দিও,
    তাহলে ফোন দূরে charging-এ থাকলেও link টা বেঁচে থাকবে।
  • ফোন restart হলেও app নিজে নিজে আবার connect হয়ে যাবে।

⭐ ২) BOOT সমস্যা fix — Nalox এবার উঠবেই:
v5.8-এর পর Nalox মাঝে মাঝে চালু হয়েই বন্ধ হয়ে যাচ্ছিল
(code 42) — কারণটা ধরা পড়েছে: আগের একটা বন্ধ হয়ে যাওয়া
Nalox-এর পুরনো নম্বর (PID) দেখে নতুন Nalox ভাবত "আমি তো
চলছিই", আর চুপচাপ বন্ধ হয়ে যেত। এবার:
  • নতুন start সবসময় চলবে — পুরনো কোনো file আটকাতে পারবে না।
  • সত্যিই আরেকটা Nalox চললে সেটা জানিয়ে তবেই বন্ধ হবে
    (log-এ কারণ লেখা থাকবে, চুপচাপ আর না)।
  • চলমান Nalox জবাব না দিলে (আটকে গেলে) নতুনটা নিজেই
    দায়িত্ব নিয়ে চালু হয়ে যাবে।

⭐ ৩) ⚡ NALOX LEVEL — Command Center-এ নতুন:
SYSTEM panel-এ এবার "⚡ Nalox Level: 8/10 Lightning" —
Nalox আসলে কতটা fast, সেটা মেপে দেখাবে, আর কোন অংশটা
slow (brain / শোনা / বলা) সেটাও এক লাইনে লিখে দেবে।
সাথে brain-এর speed-ও নিজে নিজে মানিয়ে নেবে: FreeLLMAPI
slow হলে দ্রুত provider আগে উত্তর দেবে।

⭐ ৪) ভেতরের আরও fix:
  • কোনো model এবার তার ভেতরের code/markup মুখে বলে

  ৬ সংখ্যার code দেখাবে।
